## Overview

A reverse-mode automatic differentiation engine, implemented from scratch on top of NumPy. This
is the same core mechanism — building a computational graph of tensor operations and running
backpropagation over it — that underlies frameworks like PyTorch and TensorFlow. I used the
finished engine to train a logistic regression classifier end-to-end, verifying that gradients
computed through the graph actually drive a real model to converge.

## Problem

Modern deep learning frameworks hide their gradient computation behind a single `.backward()`
call. Building that mechanism from scratch means solving a few distinct problems: representing a
sequence of tensor operations as a graph, deciding what order to differentiate the nodes in, and
computing the right partial derivatives — including through operations like broadcasting, where
the forward-pass shapes don't match the backward-pass shapes.

## What I built

- A **define-then-run computational graph** where each NumPy operation is recorded as a node with
  a forward and a backward rule.
- **Reverse-mode automatic differentiation**: a topological sort of the graph followed by a
  reverse traversal that composes **vector-Jacobian products** node by node — the standard
  formulation behind backpropagation.
- Gradient rules for elementwise ops, matrix multiplication, and reductions, including correct
  handling of **broadcasting** during the backward pass.
- An end-to-end **logistic regression** training loop built entirely on top of the engine, with no
  dependency on an existing autodiff library.

## Results

- A working autodiff engine that trains a real classifier (logistic regression) purely through
  graph-based backpropagation, with gradients matching hand-derived expectations.

## Trade-offs & limitations

- Built on NumPy (CPU, eager tensors), not a compiled or GPU-backed graph — the focus was on
  correctness of the autodiff mechanism, not throughput.
