## Overview

I built this website with Astro, TypeScript, and Tailwind CSS, using MDX for project pages and blog
posts. It builds to static files and deploys to GitHub Pages.

The photo wall uses responsive WebP thumbnails generated at build time, with full-size photos
loaded on demand. C++ game demos run in the browser through Emscripten and WebAssembly.
