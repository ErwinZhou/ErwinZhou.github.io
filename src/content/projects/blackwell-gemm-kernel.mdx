## Overview

A high-performance FP16 GEMM (general matrix multiply) kernel for NVIDIA Blackwell (SM100) GPUs,
written using TVM/TIRX. I started from a minimal single-tile kernel and incrementally added
optimization stages — tensor core usage, asynchronous memory movement, pipelining, and warp
specialization — until the kernel's structure converged toward what production libraries like
cuBLAS and CUTLASS do.
