## Overview

An open-source contribution to Hugging Face's `transformers` generation stack, adding suffix-based
speculative decoding: a proposer that speeds up autoregressive generation without needing a
separate draft model, by reusing repeated patterns already present in the context. I also designed
a unified verification interface so that both suffix-based and tree-based speculative candidates
can be checked in a single target-model forward pass.
